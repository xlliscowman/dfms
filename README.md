# 东方淼森 miusenphytech · 官网概念原型 v1.0

东方淼森中英文官网。保留原型的 HTML、CSS 与交互，由 Node.js 在发布前生成产品列表、单品页和联系方式。上线后直接托管静态文件。Pages CMS 通过 GitHub 管理内容和公开素材。

---

## 一、怎么打开

### 本机预览

安装 Node.js 22 或更新版本。双击 `start-preview.bat`，或在项目目录执行 `npm run preview`。浏览器打开 `http://127.0.0.1:8080/`，通过入口选择中英文。命令会从内容文件重新构建，再启动本机预览。

### 后台编辑

1. 用公司 GitHub 仓库保存本站源码。打开 [Pages CMS](https://app.pagescms.org/)，由有权限的管理员仅授权本站仓库，选择 `main` 分支。
2. 在「原料产品」修改中英文内容、功效分类、植物关联或公开附件。在「首页」修改首屏标题、主图和推荐原料顺序。在「联系方式」维护公开邮箱、电话、地址和企微二维码。图片和 PDF 可在媒体区上传后选用。
3. 新品使用固定编号。准备完成后打开「官网已上架」。隐藏产品时关闭上架开关。后台保存会写入 Git，`main` 的提交会触发构建。

迁移自原型的资料保留了原展示状态，后台的「资料已复核」初始为关闭。原型中未核对的 INCI、联系电话、详细办公地址和二维码留空，由内容负责人按正式资料填写。询盘继续生成邮件草稿，访客用邮件客户端发送。

### 发布

执行 `npm run build` 生成 `dist/`。GitHub Actions 会在 `main` 更新后生成同样的静态产物 `miusenphytech-static-site`。将 `dist/` **里面的内容**发布到公司网站主机的站点目录，选择实际主机后可把部署接到该工作流。使用 `index.html` 作为根目录入口。公开站点只需静态产物，仓库源码和后台配置放在 GitHub。

整册原料手册约 26 MiB。使用对单文件有限制的静态主机时，需确认支持这个大小，或为手册配置独立的公开存储。

> 字体通过 jsdelivr CDN 加载。**无网络时自动回退系统字体**，版式不塌，只是字形不同。需要完全离线一致，可把字体打包进目录。

## 三、技术说明

| 项 | 说明 |
|---|---|
| 技术栈 | 原生 HTML / CSS / JS，Node.js 22 生成静态页面，无第三方构建依赖 |
| 样式 | `assets/site.css` 全站共用；`assets/en.css` 仅英文页加载，用于拉丁文排印 |
| 字体 | DM Sans（英文）+ Noto Sans SC（中文），经 jsdelivr 以 `@fontsource` 加载 |
| 动效 | `IntersectionObserver` 控制入场；`prefers-reduced-motion` 已降级 |
| 折叠 | 原生 `<details>/<summary>`，无 JS 亦可展开 |
| 深链 | `?cat=分类名` 直达原料页某一类；`?plant=植物名` 直达植物并高亮 |
| 语言切换 | 每页右上角 CN / EN，逐页对应跳转 |
| 响应式 | ≤900px 折叠为汉堡菜单；≤560px 单列 |
| 表单 | 纯前端，提交后组装 `mailto:` 邮件，**没有后端** |

浏览器基线：Chrome / Edge / Safari 近两年版本。使用了 `text-wrap: balance`、`clamp()`、CSS 变量等较新特性，老浏览器降级但不崩。

## 四、设计系统

**色板**

| 变量 | 值 | 用途 |
|---|---|---|
| `--ink` | `#0B1511` | 主文字、深色块背景 |
| `--cream` | `#F3EFE6` | 主背景 |
| `--cream2` | `#EAE4D6` | 交替区块背景 |
| `--moss` | `#5C6B4F` | 辅助绿 |
| `--sand` | `#C9BBA6` | 深底辅助文字 |
| `--gold` | `#A98A5B` | 强调色（编号、链接、按钮） |

**字号**：正文 15.5–16px；区块标题 `clamp(26px, 3.5vw, 44px)`；首屏标题 `clamp(34px, 5.4vw, 74px)`；最小 9.5px（仅角标）。

**栅格**：容器最大 1320px，左右留白 `clamp(20px, 5vw, 72px)`。

**动效**：统一缓动 `cubic-bezier(.16,1,.3,1)`，入场位移 24px / 0.9s，逐项延迟 80ms。

## 六、交给技术时的建议

1. **抽模板**：header / 页脚 / 巨型菜单在 14 页里重复，接手第一步应抽成 include 或组件。
2. **内容外置**：原料目录和联系方式现由 JSON 维护，基地和新闻正文仍由页面模板维护。
3. **多语言路由**：现为 `cn-` / `en-` 两套静态文件；正式站建议 `/cn/` `/en/` 目录 + `hreflang`。
4. **表单接后端**：`mailto:` 只适合原型，正式站需接口 + 防刷 + 隐私合规。
5. **图片与性能**：素材替换后用 WebP / AVIF + `srcset`；26 MB 的 PDF 建议分章节下载。
6. **可访问性**：补 `:focus-visible` 样式与 skip link（当前 `<details>` 折叠已键盘可达）。
7. **字体**：若以欧美客户为主，可只留 DM Sans，去掉中文包，首屏快 1–2 秒。

## 七、中英版本的关系

英文版不是逐字翻译，而是按英文阅读习惯重排：

- 结构、组件、内容一一对应
- 单独一层 `assets/en.css` 调整拉丁文排印：行高 1.66（中文 1.85）、标题收紧 -0.014em、正文栏宽 62ch、小标题字距收窄
- 英文标题**不用硬换行**，由容器宽度与 `text-wrap: balance` 决定断点
- 产品名在英文版只保留注册商标名（如 `AuroArc®`），不重复中文名
- 术语按行业惯用：actives / blend / MOQ / compatibility / device-grade
